# Тестування

## Поточний стан
- **Backend:** 19 автотестів на `unittest` із `TestClient` та `dependency_overrides` (4 модулі у `backend/tests/`).
- **Mobile:** власних автотестів немає, сценарії перевірено вручну.

## Запуск backend-тестів
```powershell
cd backend
venv\Scripts\activate
pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```
Очікуваний результат: 19 тестів, у кінці `OK`.
- `test_golden_regression.py` (3): регресійний еталон ЛР3.
- `test_prediction_service.py` (6): ізольована бізнес-логіка `PredictionService`.
- `test_prediction.py` (6): HTTP-шар (15 полів, `dependency_overrides`, `STATS_PROVIDER=fake`, коди 400/404/503).
- `test_health_dependencies.py` (4): `GET /health/dependencies` (200 та 503).
## Запуск системи для ручної перевірки

```
# 1. backend (з папки backend, venv активовано)
cd C:\dev\cyberscope\backend
venv\Scripts\activate
uvicorn main:app --reload

# 2. емулятор запущено, тунель до backend (повторювати після кожного перезапуску емулятора)
adb reverse tcp:8000 tcp:8000

# 3. Android Studio: відкрити папку mobile, Run
```

Якщо `adb` не знайдено в PowerShell:
`& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" reverse tcp:8000 tcp:8000`

## Як подивитися вміст бази

У Android Studio: **View → Tool Windows → App Inspection → Database Inspector**, процес `com.example.helloworld`, база `cyberscope_history.db`, таблиця `history`. Після змін натиснути кнопку оновлення. Цим способом перевіряється, що помилки в таблицю не потрапляють.

## Регресійна перевірка після змін

Після будь-яких змін перевірити: застосунок запускається; список з 6 команд завантажується; для Natus Vincere / FaZe Clan показується 53% / 47%; помилки 400 і 404 відображаються; сума ймовірностей у JSON дорівнює 1; п'ять полів відповіді з ЛР2 на місці; успішний прогноз потрапляє в історію, помилка ні.

Backend-частину регресії покривають unit-тести, mobile-частину ручні сценарії вище.

## Типові проблеми під час перевірки

| Симптом | Причина | Що робити |
|---|---|---|
| «Failed to connect to /127.0.0.1:8000» | Немає тунелю `adb reverse` | Виконати команду `adb reverse`, перезапустити застосунок |
| «unexpected end of stream» | Тунель є, але `uvicorn` не запущений | Запустити backend з папки `backend`, перезапустити застосунок |
| `ModuleNotFoundError: fastapi` при запуску тестів | Не активовано `venv` | `venv\Scripts\activate` у папці `backend` |
| Чорний екран емулятора | Дисплей заснув або збій графіки | Кнопка живлення в панелі емулятора, при потребі Cold Boot |
| Історія зникла після встановлення застосунку | Перевстановлення або очищення даних видаляє базу | Для перевірки перезапуску закривати застосунок, а не видаляти його |
