# Тестування

## Поточний стан

- **Backend:** є автоматичні unit-тести на стандартному `unittest` (`backend/tests/test_prediction.py`), без сторонніх залежностей.
- **Mobile:** власних автотестів немає. У `mobile/app/src/test` і `mobile/app/src/androidTest` лежать лише шаблонні Example-тести, створені Android Studio, вони нічого не перевіряють у застосунку. Замість них є ручні сценарії (нижче).

## Запуск backend-тестів

З папки `backend`, з активованим `venv`:

```
cd backend
venv\Scripts\activate
python -m unittest discover -s tests -v
```

Очікуваний результат: чотири тести, у кінці `OK`.

### Що покривають тести

Тести викликають функції `calculate_prediction()` і `predict()` напряму (без HTTP-шару):

| Тест | Що перевіряє |
|---|---|
| `test_natus_vincere_vs_faze_clan_returns_expected_details` | Для Natus Vincere / FaZe Clan відповідь має рівно 15 очікуваних полів; значення внесків, балів і ймовірностей (0.53 / 0.47) збігаються з розрахунком; сума ймовірностей дорівнює 1; пояснення містить позначку про демонстраційну статистику |
| `test_equal_rounded_probabilities_have_neutral_explanation` | Для рівних округлених ймовірностей (синтетичні дані, `TEAMS_DB` не змінюється) пояснення нейтральне, без вибору фаворита (жодна команда не названа), і містить позначку про демонстраційну статистику |
| `test_same_teams_return_400` | Однакові команди дають помилку 400 |
| `test_unknown_team_returns_404` | Невідома команда дає помилку 404 |

HTTP-відповідь у цілому (JSON з 15 полями) перевірялась вручну через Swagger UI (`/docs`).

## Запуск системи для ручної перевірки

```
# 1. backend (з папки backend, venv активовано)
cd C:\dev\cyberscope\backend
venv\Scripts\activate
uvicorn main:app --reload

# 2. емулятор запущено, тунель до backend (повторювати після кожного перезапуску емулятора)
adb reverse tcp:8000 tcp:8000

# 3. Android Studio: відкрити папку mobile, Run
```

Якщо `adb` не знайдено в PowerShell:
`& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" reverse tcp:8000 tcp:8000`

## Ручні сценарії

| Сценарій | Кроки | Очікуваний результат |
|---|---|---|
| Коректні дані | Обрати Natus Vincere і FaZe Clan, натиснути «Прогнозувати» | 53% / 47%, текст пояснення і блок «Чому такий прогноз?» з внесками та балами 0.850 / 0.768 |
| Не обрано команди | Натиснути кнопку без вибору | «Помилка: Оберіть обидві команди» |
| Однакові команди | Обрати одну команду в обох списках | «Помилка: Оберіть дві різні команди» (400 від backend) |
| Невідома команда | У Swagger відправити `"team_a_name": "Navi"` | 404, `"Команду 'Navi' не знайдено"` |
| Порожнє поле | У Swagger відправити `"team_a_name": ""` | 422 |
| Backend недоступний | Зупинити `uvicorn`, натиснути кнопку | Індикатор зникає, показується помилка з'єднання |
| Повторний запит | Після помилки запустити backend, змінити вибір, натиснути кнопку | Новий результат без перезапуску застосунку |
| Здоров'я сервісу | Відкрити `/health` | `{"status": "ok"}` |

## Регресійна перевірка після змін

Після будь-яких змін перевірити: застосунок запускається; список з 6 команд завантажується; для Natus Vincere / FaZe Clan показується 53% / 47%; помилки 400 і 404 відображаються; сума ймовірностей у JSON дорівнює 1; п'ять полів відповіді з ЛР2 на місці.

Backend-частину регресії покривають unit-тести, mobile-частину ручні сценарії вище.

## Типові проблеми під час перевірки

| Симптом | Причина | Що робити |
|---|---|---|
| «Failed to connect to /127.0.0.1:8000» | Немає тунелю `adb reverse` | Виконати команду `adb reverse`, перезапустити застосунок |
| «unexpected end of stream» | Тунель є, але `uvicorn` не запущений | Запустити backend з папки `backend`, перезапустити застосунок |
| `ModuleNotFoundError: fastapi` при запуску тестів | Не активовано `venv` | `venv\Scripts\activate` у папці `backend` |
| Чорний екран емулятора | Дисплей заснув або збій графіки | Кнопка живлення в панелі емулятора, при потребі Cold Boot |
