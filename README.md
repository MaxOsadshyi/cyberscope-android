# cyberscope-android

Мобільний додаток для фанатів кіберспорту, що об'єднує розклад турнірів, 
статистику команд і гравців та AI-прогнозування результатів матчів.

## Ідея

На відміну від існуючих рішень (HLTV, Liquipedia), які надають лише сирі дані, 
додаток пропонує AI-аналітику — прогноз ймовірності перемоги команди на основі 
історичної статистики, форми гравців та результатів попередніх зустрічей.

**Дисципліни:** CS2

## Основний функціонал

- Перегляд розкладу найближчих турнірів
- Профілі команд та гравців зі статистикою
- Історія матчів та особистих зустрічей команд (head-to-head)
- AI-прогнозування результату матчу з відсотком ймовірності
- Пошук та фільтрація

## Технології

- **Платформа:** Android (Kotlin, Jetpack Compose)
- **Backend:** REST API
- **AI:** модель прогнозування на основі історичних даних матчів
